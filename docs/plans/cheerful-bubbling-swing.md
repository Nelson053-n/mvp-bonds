# Публичная образовательная страница /uchebnik (GEO-контент)

## Контекст

GEO-аудит bondai.ru (Score 71) показал главный кодовый пробел: **нет образовательного
контента под информационные запросы** («что такое YTM», «виды облигаций», «риски») —
это главный канал AI-цитирования (ChatGPT/Perplexity/Google AIO).

Ключевая находка при разборе: **контент УЖЕ написан** — это «Справочник инвестора»
(`GUIDE_CONTENT` в `app/ui/dashboard.html` ~стр.10539): 5 разделов (Основы, Виды,
Показатели, Риски, Глоссарий) профессионального текста про облигации, YTM, оферту,
дюрацию, флоатеры, ИИС и т.д. Но он **заперт в `/app` за логином** и закрыт от
индексации (`robots.txt: Disallow /app`) — AI/поиск его не видят.

Решение (выбор пользователя): вынести этот контент на **одну публичную страницу
`/uchebnik`** с якорями-разделами, расширив под информационные запросы (пример расчёта
YTM, FAQ-блок), с Article + FAQPage schema. Не писать с нуля — переиспользовать
выверенный текст гайда.

## Что делаем

### 1. Новый файл `app/ui/uchebnik.html`

Структура по образцу `app/ui/privacy.html` (тот же `<head>`, топбар, футер, inline CSS,
дизайн-токены `--slate`/`--blue`, шрифт Inter). Отличия:

**`<head>`:**
- `<title>Учебник по облигациям — что такое YTM, оферта, виды и риски | Bond AI</title>`
- meta description под запросы (облигации, доходность к погашению, ОФЗ, ВДО).
- `<link rel="canonical" href="https://bondai.ru/uchebnik">`, `robots: index, follow`.
- **JSON-LD: два блока** —
  - `Article` (@type Article, headline, author=Organization Bond AI, datePublished,
    inLanguage ru, about: облигации).
  - `FAQPage` с 5–7 Q&A под реальные запросы («Что такое YTM?», «Чем оферта отличается
    от погашения?», «Что такое НКД?», «ОФЗ или корпоративные?», «Что такое флоатер?»,
    «Облагается ли купон НДФЛ?»). Ответы — из глоссария/гайда.

**`<body>`:**
- Топбар с лого (как privacy.html) + ссылка «На главную».
- `<nav>` оглавление с якорями на разделы (для passage-навигации AI).
- Контент разделами `<section id="...">` с H2/H3:
  1. `#osnovy` — Что такое облигация (из GUIDE_CONTENT.basics)
  2. `#vidy` — Виды облигаций: ОФЗ/муни/корп/ВДО, типы купона, сроки (.types)
  3. `#pokazateli` — Показатели: чистая/грязная цена, НКД, **YTM с примером расчёта**,
     купон, рейтинг, оферта (.metrics + расширить примером YTM-формулы)
  4. `#riski` — Риски и как их снизить (.risks)
  5. `#slovar` — Глоссарий терминов (.glossary)
  6. `#faq` — FAQ-блок (видимый, дублирует FAQPage schema)
- CTA-блок «Попробуйте Bond AI» со ссылкой на `/app` (конверсия + внутренняя перелинковка).
- Футер с ссылками `/privacy`, `/terms`, `/` (как landing).

**Контент:** взять HTML из `GUIDE_CONTENT` (dashboard.html ~10539-10724), переложить
из `guide-card`/`guide-term-row` классов в семантические H2/H3/p/dl. Расширить раздел
YTM конкретным числовым примером (купон 8.5%, цена 97%, до погашения 3 года → YTM ≈ X%).
Текст НЕ выдумывать сверх гайда — только реструктурировать + добавить примеры/FAQ из
уже описанных в гайде фактов.

### 2. Регистрация роута — `app/main.py`

В `_PUBLIC_HTML_PAGES` (~стр.586) добавить:
```python
"/uchebnik": _ui_dir / "uchebnik.html",
```
Получит `_PUBLIC_CACHE_HEADERS` (public, max-age=3600) + security через middleware
автоматически. Паттерн цикла-регистратора менять не нужно.

### 3. sitemap.xml — `app/main.py` (~стр.523)

Добавить `<url>` блок: `loc=https://bondai.ru/uchebnik`, `lastmod=2026-06-08`,
`changefreq=monthly`, `priority=0.7` (выше privacy/terms — это контентная страница).

### 4. llms.txt — `app/main.py` (~стр.551)

В раздел «Продукт» добавить строку:
`- [Учебник по облигациям](https://bondai.ru/uchebnik): Что такое YTM, оферта, виды
облигаций и риски — образовательный материал.`

### 5. Ссылки в навигации

- **Футер landing.html** (~стр.2128): добавить `<a href="/uchebnik">Учебник</a>` между
  `/terms` и «Данные предоставлены MOEX».
- **Футер privacy.html / terms.html / uchebnik.html**: добавить ту же ссылку для
  перелинковки (AI ценит внутренние связи).

## Файлы

- `app/ui/uchebnik.html` — **новый**, по образцу privacy.html + контент из GUIDE_CONTENT
- `app/main.py` — роут в `_PUBLIC_HTML_PAGES`, sitemap, llms.txt
- `app/ui/landing.html` — ссылка в футере
- `app/ui/privacy.html`, `app/ui/terms.html` — ссылка в футере (перелинковка)

## Не входит

- Отдельные URL на каждый раздел (выбрана одна страница).
- Изменение `GUIDE_CONTENT` в dashboard.html — он остаётся как есть для in-app гайда
  (контент дублируется намеренно: in-app модалка + публичная страница — разные аудитории).
- Article schema на privacy/terms (не контентные страницы).
- SW bump (статичные страницы не в SW-кэше).

## Проверка

1. **Локально:** `import app.main` OK; `pytest` зелёный (новый роут аддитивен).
2. **Прод после деплоя:**
   - `GET /uchebnik` → 200, `Cache-Control: public, max-age=3600`.
   - HTML содержит H1/H2, оба JSON-LD блока (Article + FAQPage) валидны
     (проверить `@type`, что FAQ Question'ы парсятся).
   - `GET /sitemap.xml` содержит `/uchebnik`; `GET /llms.txt` содержит ссылку.
   - robots.txt НЕ блокирует `/uchebnik` (под `User-agent: *` нет Disallow на него —
     проверить, что не попадает под существующие Disallow-префиксы; `/uchebnik` чистый).
3. **Контент-валидация:** видимый текст ≥ 1500 слов, разделы с якорями кликаются,
   ссылка из футера лендинга ведёт на страницу.
4. **Визуально:** страница в едином стиле (тёмная тема, Inter), футер/топбар как у privacy.
